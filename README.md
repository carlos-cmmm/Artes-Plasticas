# Artes-Plasticas

Hub Artes Plásticas: um guia da arte brasileira e cearense, com abas por estado, movimento artístico e período histórico, uma aba de esculturas, um catálogo A–Z e a indicação de onde ver cada artista.

- Hub: `index.html`
- Exposição virtual da Pinacoteca do Ceará: `exposicao-pinacoteca.html`

As imagens são carregadas diretamente dos sites de origem (MASP, Pinacoteca do Ceará, jornais e sites de arte), com o link da fonte em cada obra.
